# MIDI示例曲库

播放器会自动扫描本目录中的`.mid`和`.midi`文件。也可以在软件中点击“打开任意 MIDI”，载入其他目录的文件。

## 获取开放示例

- 可从Mutopia下载贝多芬《Für Elise》，然后放入本目录：
  - 曲目：L. V. Beethoven，Für Elise，WoO 59
  - 来源：[Mutopia Project, Music ID 931](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=931)
  - 页面标注：Public Domain
  - 原始MIDI：https://www.mutopiaproject.org/ftp/BeethovenLv/WoO59/fur_Elise_WoO59/fur_Elise_WoO59.mid
  - 为保持Git仓库轻量，本工程不再提交MIDI歌曲文件。

Mutopia提供大量可下载、演奏和再分发的开放乐谱/MIDI；每首曲目的具体授权以它的曲目页面为准。曲库入口：<https://www.mutopiaproject.org/browse.html>。

## 关于《The Truth That You Leave》

该曲是现代版权作品，本工程不直接附带来源和授权不清楚的MIDI。播放器不限制曲名或音域：将你合法取得的标准MIDI文件放进本目录，或直接使用“打开任意 MIDI”即可播放。
