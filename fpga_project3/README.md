# Tang Primer 25K USB-MIDI加法合成器与数字效果器

本工程是当前发布版本。USB-MIDI枚举由RV32I软核负责，所有逐采样音频运算均由RTL完成。Primer 25K当前采用“12复音 × 每音16个正弦谐波”的加法合成结构，并支持C2/C3/C4/C6四组音色基准、音色插值和四基准动态低通包络。

## 音频链路

```text
25键USB-MIDI键盘
  -> Dock USB-A Host
  -> USB1.1 PHY/SIE + RV32I枚举/MIDI协议
  -> 48/50 MHz事件邮箱
  -> 普通直通 / 和弦记录与上下扫弦事件调度
  -> 12声部音符分配、力度和延音踏板
  -> 4基准参数插值
  -> 两路并行四分之一正弦ROM，分时计算12 x 16个谐波
  -> 四基准动态低通包络（6/12 dB/oct或旁路）+ 每声部ADSR
  -> Pitch Bend + Vibrato + Portamento
  -> 0 dB总音量混音与16位饱和
  -> Chorus -> Reverb
  -> I2S -> MAX98357 -> 扬声器
```

软核只输出MIDI事件，不生成音频采样。每个声部独立保存音高、相位、力度、按键状态、ADSR、Pitch包络、滤波包络和两级滤波器状态。

## 四基准谐波插值

默认基准音为MIDI 36/48/60/84，即C2/C3/C4/C6。每个基准包含：

- 16个Q1.15谐波初始幅度；
- 64点对数截止频率包络和独立遍历时间。

中间音符在左右基准之间进行Q0.5近似线性插值。C2～C3和C3～C4各为12个半音；C4～C6为24个半音，C5正好使用C4与C6参数各50%。5位比例让这个两八度区间内的每个半音都有独立音色位置，并用查表避免硬件除法。C2以下使用C2参数，C6以上使用C6参数。低音覆盖比原布局多一个八度；因为原C5参数本就接近C4/C6的中点，移除独立C5基准对当前预设的影响很小。

动态低通按下式逐样本更新：

```text
y[n+1] = y[n] + alpha(fc[n]) * (x[n] - y[n])
```

截止频率`fc[n]`由64点曲线和遍历时间决定，中间音符同时插值左右两个基准的曲线和时间。一级为约6 dB/oct，两级串联为约12 dB/oct；关闭IIR时谐波和直接进入ADSR。历史JSON中的每谐波衰减字段仍保留供以后高精度模式使用，但当前高复音RTL不读取也不发送它。

高音区只计算满足 `harmonic_frequency < 0.45 * sample_rate` 的分量，防止超过奈奎斯特频率后产生混叠。

## 分时计算预算

- 系统时钟：50 MHz；
- 音频采样率：48.828125 kHz；
- 每个音频采样周期：1024个系统时钟；
- 两路谐波并行查表和乘法，每4个状态完成2个谐波；
- 最坏12声部仍低于每采样1024个系统时钟的硬预算。

两份物理四分之一正弦ROM为两条并行读通道服务，乘法流水线由全部声部共享。每个声部的相位和包络状态仍相互独立。当前完整布局布线结果为Logic 76%、CLS 91%、BSRAM 58%、DSP 63%；50 MHz域实际Fmax 50.057 MHz且setup/hold违例均为0，因此12复音是25K当前稳妥配置。

## MIDI功能

| 消息/控件 | 用途 |
| --- | --- |
| `90 nn vv` | Note On，音高和力度 |
| `80 nn vv` | Note Off |
| `90 nn 00` | 按Note Off处理 |
| `B0 14 vv` / MODE旋钮 | 总音量0～127 |
| `E0 ll hh` / PITCH滑条 | 14位手动弯音，范围±2半音 |
| `B0 01 vv` / MOD滑条 | 颤音深度，最大±0.5半音 |
| `B0 15 vv` / OCT旋钮 | Chorus干湿比例，0为旁路 |
| `B0 16 vv` / LATCH旋钮 | Portamento时间，0为关闭 |
| `B0 17 vv` / GATE旋钮 | 当前保留，Delay已为释放资源而移除 |
| `B0 18 vv` / SWING旋钮 | Reverb干湿比例，0为旁路 |
| `B0 19 vv` / TEMPO旋钮 | 当前保留，暂不控制音频参数 |
| `B0 1A vv` / RATE旋钮 | 颤音速度约3～9 Hz |
| CC64 | 延音踏板 |
| CC123 | All Notes Off |

最大复音数为12。没有空闲声部时，优先复用包络电平最低的声部。Release尚未结束的音符仍占用声部。

所有效果器上电默认旁路，先保持原始音色。不同厂商键盘若使用标准CC91/CC93，也可分别控制Reverb/Chorus。

## 吉他扫弦模式

板上复位后默认为普通演奏。上位机切换到吉他扫弦后，琴键Note On/Off不再直接发声，而是静默记录最多6个和弦音；现场演示推荐按住3～4个音。当前M-VAVE键盘的Pad 1（通道10、音符`0x28`）从低到高下扫，Pad 2（音符`0x29`）从高到低上扫。一次扫弦开始时会保存和弦快照，因此扫到一半改变琴键只影响下一次扫弦。

Pad力度仍直接成为各音符力度，同时按上位机深度设置影响弦间隔和高次谐波亮度。每个被扫到的音拥有独立Gate计时；同一音符再次被扫到时会替换旧计时器，避免旧Note Off切断新声音。切换模式或USB键盘断开会自动发出CC123并清空本地状态，降低卡音风险。扫弦模式强制关闭Portamento，避免多个和弦音被误当成单音Legato。

## 演奏控制的实现原理

Pitch Bend和Vibrato最终都不是改波表内容，而是修改DDS每个采样点的相位步进。工程使用一张512项Q1.16比例ROM覆盖-2～+2半音，因此MIDI弯音的音程关系是指数关系，不是粗略的线性频率偏移。MOD产生三角形低频振荡，深度最大为半个半音；RATE控制约3～9 Hz。

Portamento只在LATCH非零且新音以连奏方式按下时启动。此时复用上一声部并保持相位和包络，以固定步长靠近目标音高，是真正的单音Legato而不是两个音重叠。当前版本提供8档约0.7～671 ms的滑音时间；LATCH为0时恢复正常12复音。它最适合单音Lead演奏，普通钢琴和弦应将LATCH置零。

## 后级效果的实现原理

- Chorus不是多开几个合成振荡器。它保存约9～17 ms的历史音频，用0.35 Hz低频振荡器移动读取位置，再把这个时而稍快、时而稍慢的延迟副本与原声叠加。因此副本会产生轻微动态失谐，听起来像多人齐奏。
- Reverb使用1499、1777、2137采样三条不同长度的反馈梳状延迟模拟不同墙面反射，再通过521采样全通扩散器把离散反射打散成密集尾音。三路反馈为3/4、输入注入为1/2，保留上一版明显的0.7～1.0秒尾音。所有反馈加法均先符号扩展到32位再饱和，避免16位中间结果回绕后将错误符号写回延迟RAM。SWING控制混响量。

为适配25K资源，已删除独立Delay大缓存，保留Chorus与Reverb。Chorus干湿旋钮量化为12.5%、25%、37.5%、50%四档；Reverb采用更明显的12.5%、37.5%、62.5%、75%四档。旋钮0保持真正旁路，处理顺序为`Chorus -> Reverb`。

## 串口上位机

板载USB-C的BL616调试串口同时承担两件事：

- FPGA到电脑：USB软核输出枚举与MIDI调试文本；
- 电脑到FPGA：RTL接收115200 baud二进制音色参数。

两个接收端可以同时观察 `uart_rx_pin`，不需要增加新的引脚。使用上位机时必须先关闭占用同一COM口的串口助手。

除音色参数编辑外，当前UART还可注入标准MIDI事件。运行`tools/launchers/run_uart_midi_player.bat`后可播放任意标准`.mid/.midi`，歌曲音符使用MIDI 0～127完整范围，不受实体25键当前OCT档位限制。软件显示歌曲音域、峰值复音和全音域琴键，支持播放/暂停/停止/跳转、0.5～1.5倍速度、±24半音移调、力度比例和鼠标试音。暂停、停止、跳转或退出都会发送延音关闭和All Notes Off。

串口歌曲与USB键盘在合成器入口处仲裁：上位机自动演奏时，实体键盘仍然在线，MODE旋钮的CC20仍控制板端总音量。当前音源为12复音，复杂MIDI超过12个同时音符（包含Release尾音）时会触发现有声部抢占。

安装依赖并启动图形编辑器：

```powershell
cd tools
.\launchers\install_python_requirements.bat
.\launchers\run_harmonic_editor.bat
```

编辑器启动所用的那个Python必须安装`pyserial`。其他串口助手能够看到COM口，并不代表这个Python环境已经装好串口库。编辑器在缺少`pyserial`时会用Windows接口尝试列出COM名并给出提示，但发送仍需先执行安装脚本；串口框也允许直接输入`COM11`一类端口名。

编辑器支持：

- C2/C3/C4/C6四个页面，每页用可拖动柱状图编辑16个谐波幅度；
- 用0～4倍倍率同时缩放当前基准或全部四个基准的16个谐波；
- 将当前基准的谐波幅度和一键归一到1；
- 实时预览当前基准的单周期加法合成波形，并显示幅度和、峰值、RMS及削顶警告；
- 为C2/C3/C4/C6分别编辑64点动态截止频率曲线和遍历时间，中间音符由FPGA自动插值；
- 可选择6 dB/oct、12 dB/oct或关闭IIR原声直通；
- 可编辑Attack、Decay、Release三张256点幅度曲线，以及A/D/S/R时间和电平；
- 可编辑256点Pitch包络及总遍历时间，纵轴可选±0.5、±1、±2、±12、±24半音，并试听动态滤波、幅度和Pitch共同作用后的声音；
- 可切换查看单段曲线或包含Note Off位置的完整ADSR总形状；试听时16根谐波柱按当前低通频响和ADSR实时显示；
- JSON保存/载入；
- 一次发送全部谐波、两组包络和演奏设置，也可只发送扫弦设置或包络。

谐波和滤波参数写入活动配置后对下一次Note On生效；幅度/Pitch表和滤波表均为可写单缓冲RAM。发送前应先松开全部琴键，避免正在读表时出现一部分旧曲线、一部分新曲线。

单周期波形预览显示16个谐波初始构成；包络窗口试听则运行与FPGA一致的动态低通、ADSR和Pitch链路。整体倍率会直接改写界面中的16个幅度，放大后若复合波峰值超过1，曲线变红并提示可能削顶。

## 乐器录音频谱分析器（第一阶段）

`tools/apps/instrument_spectrum_analyzer.py`用于从真实乐器的单音录音中提取音色参数，和UART谐波编辑器相互独立，不会占用串口或修改FPGA参数。启动：

```powershell
cd tools
.\launchers\install_python_requirements.bat
.\launchers\run_instrument_analyzer.bat
```

输入支持WAV、AIFF/AIF和FLAC。推荐使用University of Iowa Musical Instrument Samples中的单声道录音，尤其是吉他的`Guitar.mono.2496.zip`；不要优先使用MP3，因为有损压缩会改变高频频谱。

第一阶段功能：

- 选择声道、单音起止时间和已知MIDI音高；音高可输入`60`、`C4`、`F#3`，留空则自动估计；
- 2048/4096/8192/16384点STFT频谱瀑布图；
- 原始波形、瀑布图和光标时刻的32谐波柱状图联动；单击任意时刻即可查看当时的谐波构成，单击柱子可选择对应谐波；
- 瀑布图采用黑紫—蓝—青—绿—黄—红高对比热力配色，可打开近乎全屏的独立热力图；浮动小窗实时显示鼠标所指频点在整段录音中的幅度变化；
- 默认让前32次谐波刚好占满纵轴，低音不再被固定20 kHz范围压在底部；也可切换为手动频率上限，可调20～140 dB动态范围；
- 鼠标沿瀑布图上下移动时，单独曲线实时显示对应频率点在整段录音中的幅度变化；
- 播放、暂停/继续和停止当前原始音频选段，白色播放时间线、选定时刻和谐波柱状图同步移动；96 kHz等采样率会按默认声卡采样率自动转换；默认试听自动增益最高提升42 dB，只改变声卡播放，不改变分析值和导出数据；
- 跟踪前32次谐波的局部峰值频率、相对幅度、dB和相位；
- 显示实测频率相对整数倍谐波的cent偏差；
- 对每条谐波拟合指数衰减时间常数`tau_ms`和`T60`；
- 导出`gowin-instrument-analysis-v1`完整JSON和逐帧CSV。

对于连续音阶文件，先在波形/瀑布图中观察音符位置，再填写一个单音的起点、终点和音高重新分析。4096点适合作为默认折中；2048点更容易观察拨弦瞬态，8192/16384点的低频频率读数更精确但时间变化会更模糊。

表格中的“峰值Hz”是在每一帧内、理论`k×f0`附近搜索并插值得到的局部频谱峰。它可以显示钢琴弦刚度引起的非谐性，但也会受FFT分辨率、窗函数、噪声、琴体共振和基频跟踪误差影响，因此不能把单帧数值当成绝对精确的物理频率；判断非谐性应观察多个稳定帧，并优先用8192或16384点FFT分析低音。

阶段一分析JSON暂时不直接发送给FPGA；阶段二程序会重新读取四个单音并按相对衰减模型生成四基准音色。

### 阶段二：四基准音色构建

阶段二使用独立程序，不修改阶段一分析器：

```powershell
cd tools
.\launchers\run_timbre_builder.bat
```

程序固定采用C2/C3/C4/C6四个基准，可分别选择单音录音和有效时间范围。完成分析后会显示四组32谐波起始柱状图，以及每项的绝对衰减、相对衰减和最终Q0.24系数；可以对选中基准进行原声、16谐波和32谐波A/B试听，并导出`gowin-relative-timbre-v2` JSON。

导出文件的顶层`anchors`包含当前25K硬件可直接使用的4×16参数，`analysis_32`保留4×32完整分析。该JSON可直接载入现有谐波串口编辑器并点击“发送全部”，原始4×16衰减表会保持不变，也可在编辑器中逐项调整。

这里不能直接使用阶段一测得的绝对衰减。RTL最终幅度为`谐波幅度 × 单谐波衰减 × ADSR`，直接写入绝对衰减会把总包络计算两遍。阶段二使用32谐波合成能量作为总包络`G(t)`，拟合`H_k(t)/G(t)`，因此导出的单谐波系数只描述音色构成随时间的变化，ADSR仍独立控制整体响度。更完整的文件导航见`tools/README.md`。

## 25键与OCT档位核对

工程采用MIDI标准`A4=69=440 Hz`，并按`C4=60`命名。USB软核把键盘的`data1`音符号原样送给RTL，RTL直接用它读取128项DDS相位步进表，没有再次加减八度。你提供的OCT -3抓包中，最左五键为`0C/0D/0E/0F/10`，即十进制12～16，证明25个琴键是从C开始连续排列，OCT每档移动12个半音。

| 键盘OCT档 | 最左键～最右键MIDI号 | 工程音名范围 |
| ---: | ---: | --- |
| -3 | 12～36 | C0～C2 |
| -2 | 24～48 | C1～C3 |
| -1 | 36～60 | C2～C4 |
| 0 | 48～72 | C3～C5 |
| +1 | 60～84 | C4～C6 |
| +2 | 72～96 | C5～C7 |
| +3 | 84～108 | C6～C8 |

因此键位对应关系正确：例如OCT 0最左键是MIDI48/C3，第13个键是MIDI60/C4，最右键是MIDI72/C5。四基准C2/C3/C4/C6对应MIDI36/48/60/84。OCT -3的最低音只有16.35 Hz，普通小扬声器很难重放；OCT +3最高C8约4186 Hz。极低音听起来很小或近似无声时，应先区分扬声器频响与MIDI映射问题。

命令行示例：

```powershell
cd tools
python -m cli.uart_synth_control COM11 send-preset .\presets\instrument_4anchor_relative_decay.json
python -m cli.uart_synth_control COM11 harmonic-amp C4 3 0.25 --commit
python -m cli.uart_synth_control COM11 harmonic-decay C4 3 1800 --commit
python -m cli.uart_synth_control COM11 adsr 30 500 0.18 800
```

```text

CHECKSUM = XOR(CMD, DATA0..DATA7)
```

## 默认音色文件

- `tools/presets/instrument_4anchor_relative_decay.json`：当前上电及上位机默认音色，由四段真实乐器单音分析得到C2/C3/C4/C6的幅度和相对谐波衰减；缺少的曲线字段会补为A/D/R曲率0.9/0.6/0.3和水平Pitch包络；
- `tools/presets/pianotone2.json`：保留的上一版安全归一化钢琴预设，可手动载入比较；
- `tools/presets/additive_piano_4anchor.json`：另一组可载入的加法合成预设；
- `src/generated/additive_sine_quarter_512.mem`：512点四分之一正弦ROM，两路物理读通道共享同一内容；
- `src/generated/additive_harmonic_amp.mem`：4 × 16默认幅度；
- `src/generated/tone_amp_envelope_tables.mem`：Attack、Decay、Release打包后的3 × 256点幅度曲线；
- `src/generated/pitch_envelope_ratio.mem`：256点Q4.12 Pitch频率倍率初值；
- `src/generated/filter_envelope_4anchor.mem`：4 × 64点动态截止频率包络；
- `src/generated/filter_alpha_256.mem`：80 Hz～12 kHz对数映射的一阶滤波系数表；
- `src/generated/midi_note_gain_q14.mem`：128音符Q2.14上电响度补偿曲线；
- `tools/generators/generate_additive_tables.py`：从JSON重新生成全部初始化表和定点时间参数。

修改默认JSON后重新生成：

```powershell
cd tools
python -m generators.generate_additive_tables
```

## 长时间演奏的数字自恢复

实际音量较小，目前不再把MAX98357过温/过流当作主要根因，并已撤回专门针对功放保护的100 ms I2S停钟和混响降增益。当前针对可证实的数字风险处理：

1. 原USB MIDI驱动收到Bulk-IN STALL后会进入永久`midi_idle`，心跳可以继续，但从此不再轮询键盘。现改为STALL或连续16次传输错误后自动重置根端口并重新枚举；
2. USB软核等待MIDI邮箱时增加20 ms超时，不再被一次丢失应答永久卡住；
3. FPGA监视软核每秒的UART心跳。连续3秒没有任何UART写操作时，自动复位USB软核、跨时钟邮箱和音频状态，之后键盘会重新枚举；
4. 合成器状态机若约1.3 ms仍未回到空闲态，会就地清除异常声部；
5. 效果器的混音、Comb和All-pass加法全部改为32位中间结果后再饱和，避免反馈状态发生16位回绕；
6. 力度增益从通过动态声部索引直接驱动乘法器，改为Note On时预计算、渲染时寄存。50 MHz域最差布线余量从0.089 ns提高到0.355 ns。

如果实板再次静音，请保留115200串口输出：若看到新的启动Banner和枚举信息，表示硬件看门狗捕获了软核停滞；如果出现`USB-MIDI endpoint stalled; re-enumerating`或`USB-MIDI repeated errors; re-enumerating`，表示端点自恢复被触发；如果心跳、NOTE ON和NOTE OFF均正常却仍无声，才应继续检查I2S/功放链路。

RTL回归测试位于`sim/tb_midi_poly_synth.v`、`sim/tb_midi_poly_audio.v`和`sim/tb_midi_strum_controller.v`。前两者覆盖四个锚点、插值和完整音频输出；扫弦测试台覆盖普通直通、静默记录和弦以及上下扫顺序。Python测试还检查扫弦UART包布局、校验和与参数边界。

首次上板按以下顺序验证：

1. 下载 `impl/pnr/fpga_project.fs`；
2. 打开115200串口，确认USB Host每秒心跳；
3. 插入MIDI键盘，确认枚举到MIDIStreaming接口；
4. 单音检查16谐波音色和Release；
5. 依次测试2、4、8、12个同时音符；
6. 关闭串口助手，打开谐波编辑器发送默认预设；
7. 重新按键，分别修改C2/C3或C4/C6两个基准后试听中间音的插值效果；
8. 用频谱软件检查基频与有效谐波峰，确认高音区没有折叠混叠。
9. 在编辑器选择“吉他扫弦”，只发送演奏设置；按住C-E-G后分别敲Pad 1和Pad 2，确认上下扫顺序与力度变化。
